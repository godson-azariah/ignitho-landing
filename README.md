# Ignitho AI — landing site

The marketing site for Ignitho's nine AI suites: a home page, a page for each
suite, and a questions page.

    npm install
    npm run dev      run it locally
    npm run build    produce the publishable version in dist/
    npm run lint     check the code
    npm run check    draw every page and popup once, to catch a broken one

Built with React and Vite. No database, no server, no accounts — the site is a
set of files a browser reads.

## Where to look

**[DOCUMENTATION.md](DOCUMENTATION.md)** is the full guide: the file and folder
structure, what every file is, how each part works, how to make common changes,
and the house rules for design and writing. Start there.

Every source file also opens with a plain-English note saying which part of the
website it draws.
